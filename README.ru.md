# Roistat MCP

MCP-сервер для аналитики Roistat. Позволяет получать отчёты, сравнивать периоды и разбирать заказы, заявки, звонки и воронки продаж из AI-ассистента.

## Что умеет

- Аналитические отчёты, сравнение периодов и ежедневная статистика.
- Чтение заказов, заявок, звонков, визитов, клиентов и воронок по разрешённым проектам.
- Просмотр значений измерений и пользовательских метрик при подготовке отчёта.

## Установка

Нужны Git, [uv](https://docs.astral.sh/uv/getting-started/installation/) и Python 3.12–3.14.

Нужны API-ключ Roistat и ID проектов, к которым вы хотите дать доступ. Настройщик сохраняет ключ локально и задаёт список проектов.

```sh
git clone https://github.com/zai-one/roistat-mcp.git
cd roistat-mcp
uv sync --frozen
uv run --frozen python scripts/configure.py
uv run --frozen roistat-mcp --config mcp.local.json --check-config
uv run --frozen roistat-mcp --config mcp.local.json
```

Настройщик сохраняет данные только локально. `--check-config` проверяет локальную
конфигурацию без запросов к провайдеру. Последняя команда ждёт подключения MCP-клиента.

Инструкции подключения и установки пакета: [INSTALL.md](INSTALL.md).

## Возможности и ограничения

В отчётах доступен установленный список метрик: обнаружение пользовательской метрики само по себе не добавляет её в этот список. Поддерживаемые операции записи требуют отдельной настройки и подтверждения. Подробнее: [доступ и запись](docs/RUNTIME.md).
